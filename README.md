## 🚀 À propos du projet

Ce projet est une application Full-Stack réalisée dans un **cadre académique** par une équipe de 3 étudiantes. L'objectif principal est de concevoir et développer une plateforme complète visant à simplifier les processus de recrutement et la gestion des profils professionnels.

Il fournit un environnement sécurisé pour les candidats cherchant des offres d'emploi, et pour les recruteurs (RH) qui gèrent ces offres et les candidatures.

### Fonctionnalités principales
- 🔐 **Authentification Sécurisée** : Connexion et inscription avec JWT (JSON Web Tokens).
- 👤 **Gestion de Profil** : Création et mise à jour de profils professionnels (compétences, expériences).
- 💼 **Offres d'emploi** : Publication (par les RH) et consultation d'offres d'emploi.
- 📝 **Candidatures** : Processus de candidature simplifié et suivi du statut par les recruteurs.

---

## 🛠️ Technologies Utilisées

### ⚙️ Backend (API REST)
- **Java 17** & **Spring Boot 3.1.10**
- **Spring Security & JWT** pour la protection des routes.
- **Spring Data JPA & Hibernate** pour l'ORM.
- **PostgreSQL** comme SGBD.
- **MapStruct** & **Lombok** pour la propreté du code.
- **Swagger/OpenAPI** pour la documentation de l'API.

### 🎨 Frontend (SPA)
- **React 19** avec **Vite** pour des performances optimales.
- **Tailwind CSS** pour des interfaces élégantes et responsives.
- **React Router DOM** pour la navigation côté client.
- **Axios** pour les appels réseau vers l'API Spring Boot.
- **React Hot Toast** pour des notifications fluides.

---

## 📂 Structure du Projet

Le projet est divisé en deux modules principaux, chacun ayant son propre écosystème :

- 📁 **`backend/`** : Contient le code source de l'API Java/Spring Boot.
- 📁 **`frontend/`** : Contient le code source de l'application React/Vite.
